https://mandarinlll.github.io/Rainy_hgu_tennis/

## 概要

本サイトは、北海学園大学テニスサークル「Rainy」の情報をまとめた静的Webサイトです。

サークルの紹介や活動スケジュール、イベント情報、アルバム、SNSへの導線を掲載し、参加を検討している学生や部員に向けての広報を目的としています。

また、GitHub Pagesを利用して公開しており、Webサイト制作の基礎学習とGitHubによる公開・管理の実践も兼ねています。

## 制作目的

* HTML / CSS / JavaScriptを用いたWebサイト制作の基礎を学ぶ
* GitHubを用いたコード管理・Web公開の流れを理解する
* サークルの活動内容をわかりやすく発信する
* 新入生や参加希望者が情報を得やすい広報媒体を作成する
* サークル代表として、Rainyの理念や雰囲気を外部に伝える

## 主なページ構成

| ページ      | 内容                           |
| -------- | ---------------------------- |
| トップページ   | サークル概要、特徴、活動方針、Instagramへの導線 |
| Schedule | 練習頻度、イベント情報、年間イベントのイメージ      |
| Album    | 練習・イベント・季節ごとの活動写真を紹介するページ    |
| SNS      | Instagramへの案内、参加希望者向けQ&A     |

## 主な機能・特徴

* サークルの基本情報を掲載
* 練習やイベントの活動内容を紹介
* 年間イベントのイメージを整理
* アルバムページによる活動雰囲気の可視化
* Instagramへの導線を設置
* 参加希望者向けのQ&Aを掲載
* GitHub Pagesによる静的サイト公開
